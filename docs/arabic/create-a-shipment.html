إنشاء شحنة

إنشاء الشحنة طلب واحد فقط (saveShipment). الخطوات التي قبله هدفها معرفة الأرقام (IDs) التي يحتاجها: خدمة الشحن، ومنطقة المستلم ومنطقته الفرعية. اجلبها مرة واحدة واحفظها، فهي نادراً ما تتغير.

الخطوة 1: اختر خدمة الشحن

#

احفظ id الخدمة التي تريدها: هو serviceId في الخطوات التالية.

الخطوة 2: حدّد منطقة المستلم ومنطقته الفرعية

#

المناطق هي المدن أو المحافظات، والمناطق الفرعية هي الأحياء داخلها. اجلب المناطق التي تغطيها الخدمة:

ثم المناطق الفرعية لمنطقة معيّنة باستخدام parentId:

نصيحة: حمّل القائمة كاملة مرة واحدة واربطها بالمدن والأحياء في نظامك.

الخطوة 3 (اختيارية): اعرف السعر

#

الخطوة 4: أنشئ الشحنة

#

الرد:

احفظ id وcode: ستستخدمهما لمتابعة الشحنة، ويصلانك في كل إشعار .

الحقول

#

الحقول الإلزامية:

الحقل
معناه
serviceId
خدمة الشحن، من الخطوة 1
recipientZoneId
منطقة المستلم، من الخطوة 2
recipientSubzoneId
المنطقة الفرعية للمستلم، من الخطوة 2
recipientMobile
رقم جوال المستلم
recipientAddress
عنوان التوصيل كاملاً

أهم الحقول الاختيارية:

الحقل
معناه
refNumber
رقم الطلب في نظامك. يُنصح به: يمكنك البحث به لاحقاً
recipientName، recipientPhone
اسم المستلم ورقم ثانٍ له
description، notes
محتوى الشحنة، وتعليمات للمندوب
weight (كجم)، piecesCount
الوزن وعدد القطع
price
المبلغ الذي يحصّله المندوب من المستلم (0 إذا كانت مدفوعة مسبقاً)
priceTypeCode
هل price يشمل مصاريف الشحن؟ INCLD نعم، EXCLD لا
paymentTypeCode
من يدفع وكيف: COLC تحصيل عند التسليم، PAID مدفوعة مسبقاً، CRDT آجلة… انظر الأكواد
typeCode
FDP تسليم الطرد كاملاً (الافتراضي)، PDP تسليم جزئي، PTP استبدال، RTS استرجاع طرد. انظر الأكواد
openableCode
هل يُسمح للمستلم بفتح الطرد قبل الدفع؟ Y / N
deliveryDate
تاريخ التوصيل المطلوب YYYY-MM-DD
size
{ length, width, height } بالسنتيمتر
senderName، senderMobile، senderAddress، senderZoneId، senderSubzoneId
بيانات الاستلام منك، إن كانت مختلفة عن بيانات حسابك

كل الحقول موجودة في Reference ← Types ← ShipmentInput.

تعديل شحنة

#

أرسل saveShipment مرة أخرى مع id الشحنة والحقول التي تريد تغييرها. يمكن تعديل الشحنة فقط قبل أن تبدأ شركة الشحن في التعامل معها، ويخبرك الحقل editable بذلك.
