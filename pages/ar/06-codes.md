## حالة الشحنة (`shipmentStatusCode`، `status.code`)

بالترتيب الذي تمر به الشحنة عادةً:

| الكود | الحالة | المعنى |
|---|---|---|
| `PKR` | طلب شحن | تم إنشاؤها وتنتظر الاستلام منك |
| `PKM` | قيد الالتقاط | المندوب في الطريق لاستلامها |
| `PKH` | انتظار لإعادة الالتقاط | ستُعاد محاولة الاستلام |
| `PKD` | تم الالتقاط | تم استلامها منك |
| `RJCT` | مرفوضة | رفضتها شركة الشحن |
| `RITS` | تم الاستلام بالمخزن | في مخزن شركة الشحن |
| `PRP` | جارٍ التجهيز | يتم تغليفها |
| `PRPD` | تم التجهيز | جاهزة للخروج |
| `BMT` | مناولة بين الفروع - صادر | أُرسلت إلى فرع آخر |
| `BMR` | مناولة بين الفروع - وارد | وصلت إلى الفرع الذي سيسلّمها |
| `STD` | قيد الإرسال للمندوب | تُسلَّم لمندوب التوصيل |
| `OTD` | قيد التوصيل | مع المندوب في الطريق إلى المستلم |
| `DTR` | **تم التسليم** | سُلّمت للمستلم (انظر `deliveryTypeCode`) |
| `DEX` | تعذّر التسليم | لم تُسلَّم هذه المرة (انظر `cancellationReasonId`) |
| `HTR` | انتظار لإعادة التوصيل | ستُعاد محاولة التوصيل لاحقاً |
| `RTS` | ارتجاع للراسل | ستُعاد إليك |
| `RCV` | ارتجاع للمخزن | عاد المرتجع إلى المخزن |
| `OTR` | قيد الإرجاع | في الطريق إليك |
| `RTRN` | **تم الإرجاع للراسل** | أُعيدت إليك (انظر `returnTypeCode`) |

## نوع التسليم (`deliveryTypeCode`)

| الكود | المعنى |
|---|---|
| `FD` | تم التسليم بالكامل |
| `PD` | تم التسليم جزئياً: سُلّم جزء من الطرد ويعود الباقي |

## نوع الارتجاع (`returnTypeCode`)

| الكود | المعنى |
|---|---|
| `WODF` | مرتجع بدون تحمّل أي مصروفات |
| `WFDF` | مرتجع مع تحمّل الراسل كامل مصاريف الشحن |
| `WPDF` | مرتجع مع تحمّل الراسل جزءاً من مصاريف الشحن |
| `FFC` | مرتجع وتم تحصيل كامل مصاريف الشحن من المستلم |
| `FPC` | مرتجع وتم تحصيل جزء من مصاريف الشحن من المستلم |
| `PRTS` | ارتجاع جزئي |

## نوع الشحنة (`typeCode`)

| الكود | المعنى |
|---|---|
| `FDP` | تسليم الطرد كاملاً (الافتراضي) |
| `PDP` | يمكن للمستلم أخذ جزء من الطرد فقط |
| `PTP` | طرد مقابل طرد: تسليم طرد واستلام آخر (استبدال) |
| `RTS` | استرجاع طرد من المستلم وإعادته إليك |

## طريقة الدفع (`paymentTypeCode`)

| الكود | المعنى |
|---|---|
| `COLC` | تحصيل من المستلم عند التسليم |
| `PAID` | مدفوعة مسبقاً |
| `CASH` | مسددة نقداً |
| `CRDT` | آجلة: تُسوّى معك لاحقاً |
| `VISA` | تحصيل بالبطاقة المصرفية |

## نوع السعر (`priceTypeCode`)

| الكود | المعنى |
|---|---|
| `INCLD` | `price` يشمل مصاريف الشحن |
| `EXCLD` | تُضاف مصاريف الشحن إلى `price` |

## فتح الطرد (`openableCode`)

| الكود | المعنى |
|---|---|
| `Y` | مسموح للمستلم بفتح الطرد قبل الدفع |
| `N` | غير مسموح بفتح الطرد |
